À propos de FFF (Fast For Fight)

FFF est un jeu de Course-Combat 2.5D Arcade combinant vitesse pure, acrobaties style parkour et combats frénétiques.

Règles de Victoire :

  • Formats 1v3 / 2v3 / 3v3 : Le premier arrivé fait gagner son équipe.
  • Formats 1v5 / 2v5 / 3v5 / 4v5 / 5v5 : Les trois premiers arrivés valident la victoire.
